# Daiippo Nihongo (第一歩)

Aplikasi web gratis untuk belajar bahasa Jepang dasar setara JLPT N5, dalam bahasa Indonesia: kana, 718 kosakata, 79 kanji, 37 pola tata bahasa, ulasan berjarak (SRS), latihan menulis dan menyimak, serta simulasi tes N5.

Bisa dipasang di HP dan komputer (Progressive Web App) dan tetap bisa dibuka tanpa internet setelah kunjungan pertama. Progres tersimpan di perangkat masing-masing.

## Sumber data
- Daftar kosakata JLPT N5: [open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks) (MIT), bersumber dari tanos.co.uk, dasar tag JLPT N5 di Jisho.org.
- Data kanji: KANJIDIC (EDRDG, CC BY-SA 4.0) melalui [kanji-data](https://github.com/davidluzgouveia/kanji-data).
- Urutan goresan: [KanjiVG](https://kanjivg.tagaini.net/) oleh Ulrich Apel (CC BY-SA 3.0).
- Arti bahasa Indonesia dan materi tata bahasa disusun oleh Daiippo Nihongo. Simulasi tes bukan soal resmi JLPT.
